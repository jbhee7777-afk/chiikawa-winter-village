# 치이카와 · 작은 숲 생활

최신 버전: **v11 — 집과 일거리, 인어섬**

`index.html` 또는 `chiikawa-v11-adventures.html`을 다운로드해 브라우저로 여세요. 이미지와 글꼴이 포함된 단일 HTML입니다. 이전 v10 파일도 보관합니다.

- 치이카와 집: 하얀 방, 분홍 낮은 탁자, 이불, 곰 인형, 곰 포셰트와 공부 노트
- 하치와레 동굴집: 돗자리와 이불, 골판지 상자 탁자, 리본 꽃병, 기타, 카메라
- 일거리: 꽃을 남기는 풀뽑기, 공격 예고를 보고 피하거나 사스마타로 공격하는 토벌
- 이동: 인어섬과 토벌 들판. 인어섬은 친구들과 함께 돌아오는 선택형 동굴 탐험
- 보상: 도토리와 식재료, 종류마다 하루 3회. 다음 날 초기화
- 기존 산책·낚시·미니게임·식사·트리 꾸미기 유지

집의 소품은 [치이카와 공식 하우스](https://www.segatoys.co.jp/brand/chiikawahouse/chiikawaouchi/)와 [하치와레 공식 하우스](https://www.segatoys.co.jp/brand/chiikawahouse/hachiwareouchi/)를 참고했습니다. 방 배치와 미니게임은 조작에 맞춰 구성했으며 만화 장면을 그대로 복제한 것은 아닙니다.
