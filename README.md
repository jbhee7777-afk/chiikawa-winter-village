# 치이카와 · 작은 숲 생활

개인용 게임과 소스를 비공개로 보관하는 저장소입니다.

## 실행하기

1. [chiikawa-v10-forest.html](./chiikawa-v10-forest.html)을 엽니다.
2. GitHub 파일 화면의 **Download raw file** 버튼으로 다운로드합니다.
3. 내려받은 HTML을 Chrome 또는 Edge에서 엽니다.

이미지와 게임 코드는 HTML 안에 들어 있습니다. `index.html`도 동일한 최신 실행 파일입니다. GitHub의 파일 미리보기에서는 게임이 실행되지 않습니다.

## 놀이

- 숲, 바닷가, 장터를 돌아다니며 과일·버섯·솔방울·물고기 등 재료를 모읍니다.
- 친구들과 계속 대화하고 선물을 주거나 부탁을 해결합니다.
- 달리기, 도토리 받기, 짝 맞추기, 풍선 터뜨리기, 리듬 게임 등 기존 숲 놀이를 즐깁니다.
- 치이카와의 집과 하치와레의 동굴집에서 친구들을 초대하고 모은 재료로 함께 식사합니다.
- 재료로 트리 장식 12종을 만들고 원하는 자리에 달거나 옮깁니다.

## 조작

- 이동: 바닥 클릭, 방향키 또는 WASD
- 주변과 상호작용: E 또는 오른쪽 아래 행동 버튼
- 낚시: 찌가 들어가면 낚아채고, E 또는 감기 버튼을 누르다가 줄이 팽팽해지면 놓습니다.
- 아래 메뉴: 표정, 가방, 친구 선택, 수첩, 집, 트리, 놀이

활성 버튼의 대비를 높였고, 대화 버튼은 반복해서 사용할 수 있습니다. 트리는 꾸미기 화면에서 항상 선명하게 보입니다.

진행은 브라우저에 저장됩니다. v10은 숲 게임 기반의 새 저장 슬롯을 사용하므로 v9의 기록을 덮어쓰거나 자동 변환하지 않습니다. 브라우저나 파일 위치를 바꾸면 저장 기록이 이어지지 않을 수 있습니다.

소리 설정에서 효과음과 배경음을 바꿀 수 있습니다. 우사기랩은 별도의 YouTube 플레이어에서 재생하며 인터넷 연결이 필요합니다. 영상 재생 가능 여부는 YouTube 환경에 따라 달라집니다.

## 확인한 동작

캐릭터 선택, 중복 캐릭터 방지, 반복 대화, 식재료 차감과 식사 완료, 식사 중 닫기, 트리 제작·배치·이동·회수와 저장, 채집, 낚시 보상, 오락실 진입을 자동 검증했습니다. 시작 화면과 숲·집 화면은 브라우저에서도 확인했습니다.

HTML 파일 안의 CSS와 JavaScript가 실행 소스입니다. 이전 v5 ZIP 파일들은 보관되어 있습니다.
