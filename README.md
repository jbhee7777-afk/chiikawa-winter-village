# 치이카와 작은 숲 — 출시 후보판

브라우저에서 바로 실행하는 생활 어드벤처 팬 게임입니다.

## 출시 후보판 핵심

- 아침 의뢰 → 재료 수집 → 함께 식사·꾸미기 → 하루 추억 정산으로 이어지는 생활 루프
- 화면에서 다음 행동을 알려 주는 오늘의 생활 목표
- 활동 보상, 추억 경험치, 생활 등급과 연속 기록
- 하루 활동을 정리하고 저장하는 밤의 추억 카드
- 빠른 합성 멜로디를 제거한 잔잔한 숲·집·바닷가 환경음과 낮은 코드
- 캐릭터별 집, 대화, 식사, 트리, 낚시, 채집, 풀뽑기, 토벌과 인어섬 탐험
